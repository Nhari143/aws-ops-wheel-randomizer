## 🎯 How to Use

The AWS Ops Wheel v2.0 is designed to be intuitive. Here's how to get started:

### Creating Your First Wheel

1. **Add Participants**: Type a name in the input box and click "Add" or press Enter
2. **Set Weights**: Each participant can have a weight (higher number = more likely to be selected)
3. **Create Groups**: Organize participants into separate wheels for different tenants or teams
4. **Spin the Wheel**: Click the spin button to randomly select a winner

### Weighted Selection Explained

- Participants with higher weights have a greater chance of being picked
- This is useful for on-call rotations where some team members should be selected more often
- All weights are clearly displayed and adjustable

### Multi-Tenant Groups

- Create separate wheel groups for different projects, teams, or departments
- Each group maintains its own participant list and weights
- Switch between groups easily using the group selector

### 2026 Randomizer Controls

- Set the number of results to generate (e.g., pick 3 winners)
- Use the "Next Result" button to cycle through selected winners
- View history of all past selections

## 🐛 Troubleshooting

### The wheel doesn't spin
- Make sure you have added at least two participants
- Refresh the page and try again
- Check that your browser is up to date

### Can't see all participants
- Scroll down in the participant list
- The list is scrollable if you have many entries

### The app won't open
- Ensure you extracted the ZIP file completely
- Double-click `index.html` directly, not the ZIP file
- Try a different browser
